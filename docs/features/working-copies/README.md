# Working copies with a comparison

Version 1.4 (21.10.2026), changes in [CHANGELOG.md](CHANGELOG.md)

An editor checks out a published page as a working copy, changes the copy while the original stays online, compares both, and checks the copy in.
The documentation lives with the package, with screenshots of every step: [src/interaktiv.workingcopy/README.md](../../../src/interaktiv.workingcopy/README.md).
